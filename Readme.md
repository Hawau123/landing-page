# Landing Page Project

A modern and responsive landing page built using HTML and CSS.  
This project is designed to showcase a product with attractive sections, pricing, call-to-action buttons, and clean layout.

##  Features

- Responsive navigation bar
- Hero section with background image
- Product introduction section
- Multiple content sections with images
- Pricing section
- Call-to-action buttons
- Clean and modern UI design

##  Built With

- HTML
- CSS
